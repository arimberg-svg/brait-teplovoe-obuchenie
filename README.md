# Обучение по тепловому оборудованию BRAIT

Внутренний курс для продавцов: вся климатическая линейка BRAIT, фирменный стиль сайта, как продавать каждую модель и какие сопутствующие товары класть в чек.

Открыть локально: файл `index.html` в браузере.

Публичный репозиторий: https://github.com/arimberg-svg/brait-teplovoe-obuchenie

Онлайн: https://arimberg-svg.github.io/brait-teplovoe-obuchenie/

## Что внутри

- Каждая модель — отдельная вкладка слева
- Фото на белом фоне
- Как продать, преимущества, важные ТТХ
- Допы с формулировкой «зачем именно к этой пушке»
- Преимущества бренда и развилки прямой / непрямой нагрев
